# 吴越个人主页 V2.2 更新版

## 使用方法
把此文件夹内所有文件复制到 `YueWuHHU.github.io` 仓库的根目录（覆盖同名文件），通过 GitHub Desktop 提交并推送到 main 分支。首次发布后强制刷新浏览器。

主页仍使用原来相同的一级访问密码；作品集二级密码及加密链接文件没有改变。为安全起见，此说明不记录任何明文密码。

以《全部简历吴越V2.2.docx》为内容来源，修订 8 篇发表论文及其新链接、6 篇工作论文、5 项学术会议经历、2 项学术研修营、13 项竞赛、3 项项目、12 项其它荣誉、3 项校园经历、5 项实习、3 段教育与个人评价，沿用旧版作品集。
