## 页面与排版
- 顶部导航：教育经历 / 发表论文 / 工作论文 / 竞赛获奖 / 其它荣誉 / 个人评价 / 作品集展示。

- Word 中连续的下划线内容保持为一个完整连续下划线；加粗+下划线显示为蓝色、加粗、连续下划线。

## 重要安全说明
当前 `YueWuHHU/portfolio` 仓库本身是 Public。
因此二级密码可以限制主页界面中的“全文入口”，并加密主页保存的完整访问链接，
但不能阻止技术用户直接从公开 GitHub 仓库找到原 PDF。
若要让 PDF 本体真正受二级密码保护，需要把公开仓库里的原 PDF 删除/迁移，
再改为仅上传“第1页预览图 + 加密后的 PDF 文件”。
