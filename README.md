## 部署
解压 ZIP，将文件放到 `YueWuHHU.github.io` 仓库根目录，Commit 并 Push。刷新浏览器，必要时强制刷新。

本版使用新版本化文件名 `site-20261021-v24.js` 和 `home-20261021-v24.secure.json`，避免旧脚本缓存和加密数据混用。替换完成后，旧的 `site-20261021.js`、`home-20261021.secure.json` 如不再被引用，可以从仓库删除。

## 安全提醒
GitHub Pages 静态页面的客户端密码主要限制普通浏览访问，不是服务端鉴权。作品集资源如位于公开仓库，仍可能通过公开仓库直接访问。建议不要把任何访问密码写到公开 README 或仓库提交记录中。
