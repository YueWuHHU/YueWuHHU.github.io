# Yue Wu Personal Homepage

本版根据最新上传的《全部简历吴越(2)》重新制作。

## 设计原则
- 主色只使用黑色、蓝色和白色，不使用浅灰色作为正文或结构色。
- 不再使用“内容 / 补充内容 / 时间”等表头。
- 每条经历采用“标题 + 单位/成果 + 日期 + 展开详细”的简历式排版。
- Word 中“加粗 + 下划线”的重点内容，在网页中对应显示为“蓝色 + 加粗 + 下划线”。
- 采用单页响应式设计，电脑和手机自动适配，不再维护两套重复页面。
- 使用卡通头像替代真实证件照。
- 完整内容输入密码后才解密展示。
- 密码未以明文写入 HTML / JS / README。
